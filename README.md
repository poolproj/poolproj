**Pool Project** is a command-line application built in Elixir that tracks chemical levels in pools around the world. Designed for commercial pool monitoring, this program helps pool managers determine whether a pool should be open or closed based on real-time chemical data.

## 🌍 What It Does

- Collects and processes global pool chemical level data (using dummy data for now)
- Pushes the data to a centralized database
- Analyzes pool health and flags pools for closure or clearance
- Enables commercial pool managers to track chemical balance over time

## 👤 Who It's For

This tool is intended for **pool managers** and **commercial facility operators** who want a reliable way to monitor and respond to chemical level changes in their pools.
